# GM iPhone Solo Pro

Mobile-first interactive 3D iPhone visual simulation. Not affiliated with Apple or upstream iphone-solo.

Features: touch and motion rotation, sensitivity and smoothing controls, fold-style overlay (not actual folding), local wallpaper selection, PWA offline shell.

## Publish
In GitHub open **Settings → Pages → Build and deployment → Deploy from a branch**. Select **main** and **/(root)**, then Save.

Visit the published HTTPS address in Safari, tap Enable Motion, grant permission, and use Share → Add to Home Screen.
